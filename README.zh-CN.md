### 一个还在生长的 Ecosystem

**Ecosystem** 把项目记忆、科研与独立评审、编码执行和工具连接串起来。**PI-Ecosystem** 是承载它们的桌面工作区，**Lyra** 是其中正在完善的管家与搭档。

PI 仍在本地开发，**源码尚未公开**。可以先从[交互星图](https://kennymcsimpson.github.io/#ecosystem)看看它们如何相连。
