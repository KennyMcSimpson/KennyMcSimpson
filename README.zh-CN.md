# 你好，我是 Kenny。

我做实用的桌面工具与科研软件，也为开源项目修复问题。
目前关注论文理解、智能体评测，以及可复现的实验。

[桌面工具](#桌面工具) · [研究与实验](#研究与实验) · [开源贡献](#开源贡献)

## 桌面工具

**[墨读 · MoDu Reader](https://github.com/KennyMcSimpson/modu-reader)**  
Windows 本地 Markdown 阅读器，支持数学公式、Mermaid 图表和中英双语界面。  
[下载](https://github.com/KennyMcSimpson/modu-reader/releases/latest) · TypeScript / React / Electron

**[轻单 · Qingdan](https://github.com/KennyMcSimpson/qingdan)**  
安静待在桌边的 Windows 悬浮清单，支持循环提醒，以及随临近程度变色的截止时间。  
[下载](https://github.com/KennyMcSimpson/qingdan/releases/latest) · JavaScript / Electron

## 研究与实验

**[SLM-in-SciPaper](https://github.com/KennyMcSimpson/SLM-in-SciPaper)**  
围绕原文证据分析科研论文，包含 NLP 流水线和通过 ONNX 在浏览器本地运行的演示。

**[Agentic Observer 本地工作台](https://github.com/KennyMcSimpson/gosim-agentic-observer)**  
用于 GOSIM Agentic Observer 公开练习场景的本地桌面工作台。

其他探索：[编码智能体协作](https://github.com/KennyMcSimpson/room-dev)（实验项目）、[场景表征与测试时适应](https://kennymcsimpson.github.io/measurement-scene-state/)（研究归档）。
